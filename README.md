# Machine Learning Projects

## Overview

This repository contains several machine learning projects implemented in Python using popular data science libraries.  
The projects demonstrate different machine learning techniques including regression, classification, and natural language processing.

The repository includes projects such as housing price prediction, diabetes classification, Titanic survival prediction, and SMS spam detection.

---

## Features

- Machine learning models implemented in Python
- Data preprocessing and feature engineering
- Model training and evaluation
- Regression and classification algorithms
- Natural Language Processing for text classification
- Data visualization using matplotlib

---

## Installation

Clone this repository:

```
git clone https://github.com/yourusername/machine-learning-projects.git
cd machine-learning-projects
```
Install dependencies:
```
pip install -r requirements.txt
```
